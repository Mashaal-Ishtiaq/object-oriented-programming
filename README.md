# Object-Oriented Programming (OOP)

A collection of C++ programs, practice exercises, and assignment materials for Object-Oriented Programming.

## Repository Structure

- `assignments/` — assignment-related C++ source files and folders, including `oop_assignment_3/`.
- `practice/` — standalone C++ practice programs.
- `resources/` — assignment PDFs and other reference documents.
- `compiled/` — existing compiled or extensionless files from the repository root.

## Language and Tools

- **Language:** C++
- **Compiler:** GCC (`g++`) or another compatible C++ compiler
- **Editor:** Visual Studio Code or any C++ IDE

## Compile and Run

Compile a C++ source file:

```bash
g++ path/to/program.cpp -o program
```

Run on Linux/macOS:

```bash
./program
```

Run on Windows PowerShell:

```powershell
.\program.exe
```

Replace `path/to/program.cpp` with the path to the source file you want to run.

## Notes

- Existing source code, filenames, and file contents have been preserved.
- Files that were directly in the repository root have been grouped into folders for easier browsing.
- Some programs may be independent exercises and may require specific input files or input from the terminal.
